# PROMPTS.md — История промптов

## Описание
Этот файл содержит ключевые промпты использованные при разработке дашборда с помощью Claude AI.

---

## 1. Выбор задания
«Сравни 3 варианта тестового задания для UX/UI дизайнера. Учти что я дизайнер и буду писать код с помощью AI»

## 2. Планирование
«Составь подробный план разработки AI-дашборда OEE для фармкомпании PharmaLine. Дедлайн 18:00 следующего дня, сон 7 часов»

## 3. Синтетические данные
«Создай синтетические данные для OEE дашборда: 3 линии × 3 смены × 30 дней × 3 SKU = 810 записей. Добавь реалистичные паттерны: ночная смена хуже, Линия В проблемная, поломка на 3-й неделе»

## 4. Бэкенд и AI интеграция
«Создай Vercel Serverless Function для запроса к OpenRouter API. Токен должен быть скрыт на бэке. Модель: claude-sonnet-4-5»

## 5. Промпт для AI диагностики
«Ты AI-аналитик OEE для фармацевтической компании PharmaLine. Проанализируй данные и верни JSON с аномалиями, узкими местами и приоритетными действиями с учётом GMP»

## 6. Компоненты дашборда
«Создай React компонент для donut-диаграмм A/P/Q по каждой линии. Толстое кольцо, OEE внутри, проценты снаружи»

## 7. Финансовый блок
«Добавь финансовый блок с потерями от простоев, брака и переработки. Данные должны быть реалистичными для фармпроизводства»

## 8. Симулятор
«Создай симулятор Что если — выбор параметра A/P/Q, ввод % улучшения, расчёт нового OEE и экономического эффекта»

## 9. Экспорт CSV
«Сделай экспорт CSV с несколькими секциями: сводка по линиям, сменам, SKU и детальные данные. В названии файла указать период»

## 10. Дизайн
«Сделай тёмную тему в стиле enterprise SaaS: фон #0f1117, карточки #1a1d27, акцент #6c8fff. CSS-переменные для переключения тем»

---

## Инструменты
- Claude Sonnet 4.6 — основной AI для разработки
- OpenRouter API (claude-sonnet-4-5) — AI внутри приложения
- React, Recharts — фронтенд
- Vercel Serverless Functions — бэкенд
